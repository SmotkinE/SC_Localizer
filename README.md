# SC Localizer

Русская локализация Star Citizen: программа сама качает свежий перевод, собирает его и ставит в игру.

## [Скачать последнюю версию](https://github.com/SmotkinE/SC_Localizer/releases/latest)

На странице релиза, в разделе **Assets**, — архив `SC_Localizer_vX.Y.Z.zip`.
Не «Source code»: там исходники, а не программа.

## Запуск

1. Распакуй архив в любую папку.
2. Запусти `SC_Localizer.exe`.
3. Нажми «Установить в игру».

Новые версии программа предлагает сама.

## Режимы

- **Только описания** — описания, диалоги, журнал; названия и интерфейс английские.
- **Полный русский** — всё на русском.
- **Английский с блюпринтами** — без перевода, в описаниях контрактов видно чертежи.
- **Оригинал игры** — перевод убран, родной текст игры.

## Откуда перевод

- русский — [n1ghter/StarCitizenRu](https://github.com/n1ghter/StarCitizenRu)
- английский с блюпринтами — [MrKraken/StarStrings](https://github.com/MrKraken/StarStrings)
