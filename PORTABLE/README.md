# Сборка портабл-версии

Здесь собирается автономная версия для раздачи. Исходники живут в
`..\SC_LOCALIZER\` — эта папка только для сборки, чтобы не мусорить в коде.

## Как собрать

Двойной клик по **`СОБРАТЬ.bat`**. Занимает минуту-полторы.

Результат: **`dist\SC_Localizer\`** — эту папку и раздавать.
Внутри `SC_Localizer.exe`, `_internal\` и инструкция для людей.
Python на машине пользователя не нужен.

`build\` — временный мусор PyInstaller, раздавать не надо.

## Перед раздачей

Убедись, что в `dist\SC_Localizer\` **нет** файлов `paths.json`, `profile.json`,
папок `logs\` и `output\`. Они появляются после запуска и содержат пути с твоей
машины. Программа создаст их у пользователя сама.

## Почему в папку, а не одним файлом

Однофайловая сборка (`--onefile`) при каждом запуске распаковывает себя во
временную папку. Антивирусы стабильно считают такое поведение подозрительным —
для раздачи людям это означает поток вопросов «а это не вирус?». Плюс старт
на несколько секунд дольше.

По той же причине выключено UPX-сжатие в `SC_Localizer.spec`.

## Грабли упаковки

Собрано на них, не убирать без причины:

- **`sys.executable` в собранном exe — это сам exe, а не python.** Кнопка «Обзор…»
  запускает окно выбора файла отдельным процессом (tkinter требует главный поток).
  Наивный `subprocess.run([sys.executable, 'file_dialog.py'])` в сборке запустил бы
  вторую копию программы. Поэтому exe зовёт сам себя со скрытым флагом
  `--file-dialog`, а `main()` проверяет его первым делом.
- **У оконного exe нет stdout.** Выбранный путь возвращается через временный файл,
  а не печатью в консоль — печатать некуда.
- **Данные кладутся рядом с exe, а не внутрь упаковки.** `Config` определяет папку
  через `sys.executable`, когда `sys.frozen` выставлен: внутри упаковки временная
  папка и права только на чтение.
- **Шаблон `index.html` надо класть в `datas`.** Flask ищет его на диске, в код он
  не попадает, и без этого exe падает при открытии страницы.
- **`tkinter` импортирован на уровне модуля** в `file_dialog.py` — чтобы PyInstaller
  гарантированно увидел зависимость и положил её в сборку.
